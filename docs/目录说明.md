## 不跟踪的本地文档区

性能批次报告、逐轮验收、发版准备、开发避坑汇编和日期绑定的测量数据与测试手册都在 `local-docs/repo-docs/`（本轮新增的三篇 2026-10-11 文档位于 `local-docs/repo-docs/docs/`）。它们随开发频繁变动，不适合放在仓库里跟着提交历史走；`local-docs/` 整体在 `.git/info/exclude` 下，不进入版本控制，可自由改写。目录结构按原 `docs/` 相对路径保留。`local-docs/` 另有 `application/`、`framework/`、`performance/` 三处维护者笔记；原始日志、哈希与构建证据仍在仓库忽略的 `out/`。

2026-10-11 本次整理：三篇 GPU 测量/范围报告合并提炼到渲染契约，原报告归档在 `local-docs/performance/rendering-2026-10-11/`；旧 Win32/D2D 源码分析与导图预算计划归档在 `local-docs/repo-docs/consolidation-2026-10-11/`。归档的 `originals/` 保存原始字节，外层副本仅修正相对链接；文本几何文档的旧测量记录也保留在其中。移动清单和哈希见 `out/docs-consolidation-20261011/archive-receipt.json`。本地资料不随克隆传递，团队复用所需契约仍保存在 `docs/`。

## 目录约定

| 位置 | 用途 |
|---|---|
| `docs/` | 当前维护入口、稳定流程与技术契约；不放逐轮原始过程报告 |
| `docs/examples/`、`docs/screenshots/` | 示例文档与README图片 |
| `local-docs/` | 当前克隆的本地文档区，不纳入 Git：`repo-docs/` 保存从仓库移出的过程文档，其余为维护者笔记 |
| `out/` | 构建、原始数据、日志、哈希、配置及GUI证据。构建区规范见[开发流程与交接规范第 4 节](开发流程与交接规范.md)：小改动用 `preview-1..3` 轮换覆写+截图预览；可用版本进 `stable-candidate`，用户确认后就地改名为 `stable-v*` 归档（留最近 3 个）；CMake 构建树当轮验收后即删，不堆放在 `out/` |
