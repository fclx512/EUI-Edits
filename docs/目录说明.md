## 不跟踪的本地文档区

性能批次报告、逐轮验收、发版准备与记录、日期绑定的测量数据和历史归档都在 `local-docs/repo-docs/`（2026-10-09 从 `docs/` 移出）。它们随开发频繁变动，不适合放在仓库里跟着提交历史走；`local-docs/` 整体在 `.git/info/exclude` 下，不进入版本控制，可自由改写。目录结构按原 `docs/` 相对路径保留。`local-docs/` 另有 `application/`、`framework/`、`performance/` 三处维护者笔记；原始日志、哈希与构建证据仍在仓库忽略的 `out/`。

## 目录约定

| 位置 | 用途 |
|---|---|
| `docs/` | 稳定流程说明与技术契约；不放日期绑定的过程记录 |
| `docs/examples/`、`docs/screenshots/` | 示例文档与README图片 |
| `local-docs/` | 当前克隆的本地文档区，不纳入 Git：`repo-docs/` 保存从仓库移出的过程文档，其余为维护者笔记 |
| `out/` | 构建、原始数据、日志、哈希、配置及GUI证据；保留既有轮次 |
