# 思维导图只读预览

EUI-Edits 使用现有原生图元按需绘制思维导图，不引入浏览器或完整 Mermaid 引擎。它是只读查看工具；正文仍是唯一数据来源，不提供节点编辑、导图级撤销或格式回写。

当前提供代码块内的源码/导图切换。实现与验收状态见[当前实现与验收路线](当前实现与验收路线.md)。

## 打开与操作

1. 打开包含闭合 `mermaid` / `mindmap` 代码块的 Markdown 文档。
2. 点击代码块右上角“视图”，在输入框内原位显示导图；也可将光标放入目标块，用“视图”菜单打开。
3. 在图形区域滚轮缩放，中键拖动平移；“适应窗口”恢复完整图的视野。导图放大上限随初始适应比例变化，使大图能够回到正常标签字号；普通图片仍沿用原有缩放范围。
4. 点击“源码”或按 Esc，回到可编辑源码。图形区域拥有只读焦点，普通输入不会写入隐藏源码；保存与新建等应用快捷键仍可传递。
5. 点击其他正文后可以继续编辑；光标或选区进入隐藏的目标块时，恢复源码几何。文本、文档身份、字体、DPI或主题失效时重新校验缓存或回退源码。

同一时刻显示一个导图块，其它闭合块仍有各自的切换按钮。切换、缩放和关闭不修改正文、源字节光标/选区、撤销历史或保存状态；菜单打开可能滚动到目标块首行。未闭合围栏没有切换按钮，不支持语法及超限用例保留源码并给出提示。

逻辑打开入口拒绝仍活动的 IME 组合。原生鼠标左/右键按下沿 Runtime 既有规则取消预编辑；不能把逻辑 helper 的拒绝测试解读为原生点击一定保留候选窗。实际组合、点击取消和输入法差异须分别验收。

人工查看样例位于 [`tests/assets/mindmap/manual-preview.md`](../tests/assets/mindmap/manual-preview.md)，含中文、英文、emoji、长标签、宽树、深树及回退用例。

## 支持的最小语法

````markdown
```mermaid
mindmap
  root((中心主题))
    branch[矩形节点]
      裸标签
      中文与 emoji 🌱
    other[另一个分支]
```
````

- 只支持小写 `mermaid` 围栏内的 `mindmap`，单根、空格缩进的树。
- 支持裸标签、`id[标签]` 矩形、`id((标签))` 圆形。显示标签不包含显式 id。
- 支持空行和普通 `%%` 注释；不支持 Tab 缩进。
- 布局从左向右，连线为正交折线；不是完整 Mermaid 的视觉或语义兼容。
- 不支持样式指令、外部图标、HTML/Markdown 标签、点击链接、其它节点包装、边声明及其它 Mermaid 图种。也不支持 XMind、FreeMind 或二进制导图文件。

## 边界与安全回退

单块最多 2,000 节点、深度 32、源文本 256 KiB，单个标签最多 200 个 Unicode 码点。超限或不支持的语法会整块拒绝并提示，保留原始代码块；不会偷偷丢节点或把部分图伪装成完整图。

可见节点超过 300 时进入几何概览：保留节点框和连线，省略文字并提示。放大到更小的可见范围后可恢复文字。

导图树与布局属于可重建的页自有派生缓存，随文档、目标块、字体、字号、界面缩放/DPI、视口宽度和主题条件变化失效，受派生缓存淘汰及活动预览预算约束。滚轮缩放只是几何变换，不重建布局；窗口宽度、字体或主题变化后会重新测量并复位到适应窗口。它们不属于正文或恢复文件。

导图使用输入组件的可见源行几何与独立画布裁剪，随正文滚动和可读行宽移动。视图隐藏与章节折叠的隐藏原因分开，切换不会误展开章节。当前不提供节点编辑或导图单独保存。

## 渲染测试口径

Win32 / Direct2D 的软件 DC/GDI 路径仍是默认。硬件优先路径可以用独立测试入口启动：

```powershell
pwsh -File ./scripts/start-neoeditor-preview.ps1 `
  -Exe '<本轮测试目录>/neo_editor.exe' `
  -File './tests/assets/mindmap/manual-preview.md' -Hardware
```

去掉 `-Hardware` 即为软件测试。启动脚本为每次测试创建独立 APPDATA，拒绝与现有 EUI-Edits 实例混用，不改用户 GPU 偏好或注册表。

“硬件优先”请求 Direct2D DEFAULT + Hwnd；Direct2D 可内部软件回退，目标创建失败也会重试软件。这个名称不意味着已经确认实际使用哪块 GPU，也不保证 CPU、内存、帧率或功耗收益。GUI 观感、输入法、多屏 DPI、低配与真实性能须分别验收。

## 验收范围

正式集合包含 `input_line_overlay`、`mindmap_inline_ui`、`image_viewport` 及已有解析/布局/缓存测试。实机结果与源码/EXE 身份在本地 `local-docs/performance/验收序列与导图内嵌-2026-10-11.md`；原始截图、退出与保存回执在 `out/acceptance-sequence-20261011/`。只读模型、真实窗口、性能、独立打包分别解释，具体测试数随正式脚本变化。

原生中键持续平移、长时间持续拖选、低配、多屏 DPI及真实设备丢失仍有覆盖缺口。千节点大图的可读性要看最终候选的复测；旧固定缩放上限失败记录保留。没有为导图冷开或缩放建立正式 CPU/端到端延迟 A/B，不能把工具操作耗时当性能结果。
