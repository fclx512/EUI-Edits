# 性能优化第四批：启动与打开文档后台扫描

本批处理大目录在启动/打开文档时的同步依赖。D50 同机三轮实测中，从创建进程前打点到首篇正文构建结束的中位时间由 **2.162 秒降至 0.107 秒**；该指标是应用构建 trace，不能代替窗口首次可见或首次接收输入的时间。新版三轮均先构建正文，再完成后台扫描并采纳目录。

新入口 [prepareVault](../apps/neo_editor/state/app_actions.cpp) 在冷根显示已有加载态并排后台扫描，暖根先复用快照再后台核验。启动恢复与打开新根文档使用该入口。重复访问同一在飞任务不再追加重扫；目录变更请求仍保留原来的 pending-rescan 语义。

[tickVaultScan](../apps/neo_editor/state/app_actions.cpp) 可以在页上尚无快照时采纳首代结果。采纳错误结果后结束加载态并显示错误提示，同一代次不会反复提示。新建、重命名、删除、手动选择目录等显式动作继续使用现有同步刷新，本批没有将它们整体异步化。

[侧栏定位](../apps/neo_editor/ui/vault_view.h) 等待冷扫描结果；暖快照缺少刚出现的目标时也保留定位请求，后台核验结束后再消费或清除。这两处是异步打开所必需的行为补齐。

对照的两次扫描来自打开文档和最终启动准备，均发生在首次正文构建前；新版复用一个在飞任务。`vault-root-scan` 在线程上计时，`vault-adopt` 单独记录主线程投影阶段。扫描快照的字节估算/发布仍在主线程完成，没有改为分片采纳。

三轮对照与三轮最终候选均通过 Computer Use 观察到正确正文、D50 目录行及当前文件定位，并正常 Alt+F4 关闭、退出码 0。最终候选末轮还验证正文点击、Ctrl+End 导航和普通侧栏滚动。当前文件哈希保持原值。该交互发生在目录完成后；扫描期间首帧与输入能力不能仅靠这些截图代填通过。

原始证据在 `out/performance-20261008-r4/`：`baseline-D50-r1..r3` 与 `candidate-D50-r2..r4` 各含 `launch.json`、`result.json`、`trace.csv`、resize 日志及截图。`launch-monitor.py` 负责启动和只读进程采样，UI 操作使用 Computer Use；`summarize.py` 校验候选哈希、正常退出、扫描线程/次数，并生成上述 JSON。CPU 样本仅作诊断，本批没有固定相同交互时段的整体 CPU/内存比较。

## 回归与审查

[document_vault_loading](../tests/unit/document_vault_loading.cpp) 使用真实应用动作、缓存调度、侧栏构建与文档读取，隔离系统对话框和持久化接口；可控扫描器验证：

- 文档在扫描放行前已载入，冷根加载态保留定位请求，首代结果能被 tick 采纳。
- 重复准备只运行一个任务，暖快照后台核验，不改变筛选/滚动投影的稳定代次。
- 暖快照缺少新目标时等待核验，目标到达后定位；扫描结束仍无目标则清掉请求。
- 真实 `loadDocument` 在旧根扫描中切到新根，旧根先完成不会污染当前文档/目录。
- 冷根与暖根扫描失败均清空行并提示，同代次不重复 toast，空根清空视图。

`negative-test.py` 临时使用保留的旧动作源码，并用测试适配器将 `prepareVault` 接回原同步入口；它用于行为负例，未生成实机对照 EXE。最后负例退出 1、12 项断言失败，优化版本退出 0。源码在 finally 中按原始字节恢复并校验。日志中的可控延迟与重复调用不是实机性能数据。

最终完整 Release 构建通过，`ctest -L unit -j 4` **89/89 通过**，包含文件操作、目录缓存/监听、标签页、输入、表格和渲染回归；最终单测墙钟 43.16 秒。i18n 与 whitespace 检查通过。本批未运行 `performance` 标签基准。Luna 只读盘点、审查并指出暖定位边界，主代理完成实现、构建、实机操作与证据核对。

## 未覆盖与后续

本批支持“D50 启动正文构建解除同步整树扫描依赖”，不宣称整体启动、内存或拖选问题全面解决。窗口首次可见、扫描期间首个真实输入、低配设备、硬件 GPU、真实 IME、跨显示器 DPI、更多目录规模/网络盘仍需独立验收。

OPT-001 高频滚轮停滞、B07–B11/B14、C 组和此前 SKIP 状态保持原记录。下一项可测滚轮事件消费/合并与绘制积压；目录方面还需分段量化快照发布、行投影与取消成本，之后再决定是否异步化显式刷新或局部更新。
