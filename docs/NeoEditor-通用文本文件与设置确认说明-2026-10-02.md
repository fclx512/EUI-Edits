# NeoEditor 通用文本文件与设置确认说明

NeoEditor 可打开常见文本、Markdown、源码和数据配置文件，也可以通过打开对话框的“所有文件”筛选打开其他扩展名。文档库默认列出所有文件；可主动切到“常见文本”筛选已识别类型。读取仍有 64 MiB 上限，并会拦截疑似二进制文件；扩展名只用于选择显示语言，不会绕过文本校验。

文档库会遍历所选目录下可访问的目录，不按隐藏名称、常见构建目录、层级或条目数量省略项目；符号链接和目录联接点会显示为目录项，但不跟随其目标，以避免跳出所选目录或形成循环。其他目录重解析点仍会继续枚举。扫描只读取目录项和文件类型元数据，不读取未打开文件的正文；遇到无法读取的子目录会保留其他列表并提示，库根目录不可读时会报告失败。所有文件视图可以列出二进制文件，但打开时仍由文本读取器拦截；这保留了文件完整可见性，不表示 NeoEditor 支持编辑二进制内容。

## 文件类型与显示

已识别的扩展名会选择相应显示方式：Markdown 使用 Markdown 预览，源码及部分数据/配置文件使用轻量语法着色，普通文本不做语法着色。未知扩展名按纯文本打开。`.gitignore`、README、LICENSE等特殊纯文本保留识别，使用不带字母的五横线通用文档图标；Markdown大图标纸张使用紫色调；源码/配置符号向左收窄，避开纸张折页。常见无扩展名文件也会识别，例如 `CMakeLists.txt`、`Makefile`、`Dockerfile`、`.env`、`.editorconfig`、`.gitignore`、`README` 和 `LICENSE`。

打开后可从“文件语言…”选择自动识别、纯文本、Markdown 或可用的源码/配置语言。此设置改变当前文档的呈现方式，不会改写文件内容。自动换行默认随语言类别选择，也可在“视图”菜单或状态栏切换；源码默认不自动换行，Markdown 与普通文本默认自动换行。

“文件 → 新建 → 文本”创建纯文本新文档；“文件 → 新建 → Markdown”创建 Markdown 文档。已有未保存修改时，会先显示放弃修改确认。

## 保存与换行

对未修改的已有文件按 Ctrl+S 时，NeoEditor 会提示无需保存并保留原文件。发生编辑后保存会按记录的编码、BOM 和换行风格写回；内部文本以 UTF-8 和 LF 表示。混合换行会在读入时归一化，保存时按记录的统一风格展开，因此不承诺混合换行文件逐字节保真。新文档在 Windows 上使用 CRLF。

## 文件关联

设置中的文件关联列表可勾选包括 BAT/CMD、PowerShell、Python 在内的已识别脚本，将 NeoEditor 加入 Windows“打开方式”。初始默认登记仅 TXT/MD，BAT 不自动加入；脚本是否登记由用户选择，修复会保留已选类型。应用更改只更新 NeoEditor 自己的可选打开方式和图标登记，不替用户修改 Windows 默认应用。要设为默认应用，请用“系统默认应用”入口完成选择。列表中的类型可单独添加或移除；清理全部关联不删除文稿。如果某类型当前仍以 NeoEditor 为默认程序或状态未知，需先在 Windows 设置更换默认应用并刷新后才允许移除。

会移除关联或重置设置的操作使用红色主按钮再次确认。点“取消”、关闭确认框或按 Esc 会放弃该操作。其他确认弹窗也提供相同的明确确认与取消路径。
