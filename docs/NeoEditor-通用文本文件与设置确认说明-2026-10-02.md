# EUI-Edits 文本文件与设置确认

EUI-Edits 可打开常见文本、Markdown、源码和数据配置文件，也可通过“所有文件”筛选选择其他扩展名。文本读取上限为 64 MiB，读取器核对内容及编码；图片经独立只读路由查看。

文档库默认列出所有文件，可切到“常见文本”筛选已识别类型。每层按批次读取直属目录项，每批最多 500 项；展开子目录才读取下一层，筛选仅覆盖已加载内容。扫描只读元数据，打开文件时读取正文。符号链接和目录联接点显示为条目，不跟随其目标。读取失败时保留已加载内容并提示；自动监视覆盖根目录直接子项。实现入口为 `model/vault.h`、`state/vault_cache.cpp` 和 `ui/vault_view.h`。

## 文件类型与显示

已识别的扩展名会选择相应显示方式：Markdown 使用 Markdown 预览，源码及部分数据/配置文件使用轻量语法着色，普通文本不做语法着色。未知扩展名按纯文本打开。`.gitignore`、README、LICENSE等特殊纯文本保留识别，使用不带字母的五横线通用文档图标；Markdown大图标纸张使用紫色调；源码/配置符号向左收窄，避开纸张折页。常见无扩展名文件也会识别，例如 `CMakeLists.txt`、`Makefile`、`Dockerfile`、`.env`、`.editorconfig`、`.gitignore`、`README` 和 `LICENSE`。

打开后可从“编辑 → 语法模式…”选择自动识别、纯文本、Markdown 或可用的源码/配置语言。此设置改变当前文档的呈现方式，不会改写文件内容。自动换行默认随语言类别选择，也可在“视图”菜单或状态栏切换；源码默认不自动换行，Markdown 与普通文本默认自动换行。

“文件 → 新建 → 文本”或“Markdown”创建对应的新标签，保留其他标签中的未保存内容。

编辑区右键菜单以 `markdownCapable()` 的当前语法模式为准。Markdown 模式保留链接、格式、段落与插入项；纯文本、源码、数据配置及未知类型的非 Markdown 模式只显示剪切、复制、粘贴、全选。手动覆盖为 Markdown 后恢复丰富菜单，覆盖为纯文本后精简。剪切/复制按选区启用；精简菜单不查询 Markdown 计划，关闭动画沿用最后打开的呈现，旧菜单在模式已改变后不能分发格式命令。

## 编辑区图片查看

图片的打开、文档库、拖入与启动转发共用现有解码器，在编辑区内只读显示。画布排除文件名栏和底部控制栏；放大/缩小按钮与滚轮共用中心缩放及 0.1–16 倍适应比例边界，百分比表示原图像素到逻辑像素的比例。「适应窗口」恢复适应比例并清零平移；左键或中键只平移超出画布的方向。按钮沿用主题配色、字号和圆角/直角样式，不增加图像副本、全窗滤镜或常驻定时器。

每张图片是独立只读标签，重复打开同一物理文件定位到已有页，切换时保留各自缩放和平移，可使用顶栏、标签列表、快捷键切页、重排和关闭。图片或标签关闭按钮、Esc、Ctrl+W 关闭当前图片页，不影响其他文字标签。文字的正文、光标、滚动和撤销按原有标签所有权保存；图片不执行文字编辑、查找、保存或编码转换，相关菜单禁用。窗口关闭仍确认其他脏文字页，设置往返保留当前图片视角。错误/缺失的图片恢复页保留重试入口，不按文字读入或恢复为脏稿。

## 保存与换行

对未修改的已有文件按 Ctrl+S 时，EUI-Edits 会提示无需保存并保留原文件。发生编辑后保存会按记录的编码、BOM 和换行风格写回；内部文本以 UTF-8 和 LF 表示。混合换行在读入时归一化，保存时按记录的统一风格展开。新文档在 Windows 上使用 CRLF。

“文件 → 转换为 UTF-8”明确改变当前文稿的保存编码元数据，并推进文档 revision 使其变为 dirty；它不重新打开文件，也不改正文或文本撤销历史。BOM 是否存在及统一行尾风格保持不变；若有 BOM，写出的标记字节按 UTF-8 编码重写，不保证保留原编码的 BOM 字节序列。之后按 Ctrl+S 或“另存为”走正常保存流程；取消、冲突、写入或回读核验失败时，转换意图仍留在当前脏稿和恢复数据中，直至成功保存。

## 本地 Markdown 标题链接

行内链接可附带提示文字，例如 `[文字](file.md#标题 "提示")`，也可用尖括号包住含空格的目标，例如 `[文字](<file name.md#标题> "提示")`。打开链接只使用目标地址；右键“编辑链接”只替换地址，保留原有尖括号、空白和提示文字。编辑框打开时会聚焦并全选目标；按 Enter 确认，按 Esc 取消，确认或取消后焦点回到正文。确认时若目标未改变，不产生正文改动。图片的目标编辑使用相同区间规则；这不扩展引用式链接的定义解析能力。此处说明键盘行为，不代表真实中文 IME 验收通过。

本地 Markdown 链接可用 `#标题` 跳转当前文稿，也可用相对路径加 `#标题` 打开另一份本地 Markdown 文稿后定位标题；WikiLink 目标也支持 `#标题` 片段。片段采用本应用定义的轻量标题规则：去除隐藏标记后的可见标题裁掉首尾 ASCII 空白，ASCII 字母转小写，空白和连字符折成单个连字符，常见 ASCII 标点忽略，非 ASCII UTF-8 字节保留；重复标题依次加 `-1`、`-2` 等后缀。百分号编码按 UTF-8 解码。此规则不承诺兼容 GitHub 或 Obsidian；缺失标题会提示无法定位。

## 文件关联

「设置 → 文件与系统」显示 .txt、.md 的「打开方式」登记和实际默认应用。首次可用「添加 TXT / Markdown 打开方式」为当前用户登记这两种格式。已添加后，主按钮进入 Windows 默认应用设置。能定位到 EUI-Edits 时直接打开其应用页，其他系统可按扩展名搜索。主窗口重新激活后读取一次最新状态，查询失败时显示「待确认」。

移动或重命名 EXE 后，可从新位置运行，再点「修复打开路径」。修复使用已登记的扩展名集合，并重写打开命令和图标路径。双击默认应用由用户在 Windows 中选择。

「自定义文件类型」提供搜索、分类、逐项勾选和移除入口。勾选只改变待提交选择，应用前可查看新增、移除数量。移除需要确认。如果受影响的格式仍由 EUI-Edits 默认打开或状态无法确认，页面会提示这些格式，可先打开 Windows 设置处理。写入失败时保留待选集合。取消确认、关闭确认框或按 Esc 会放弃当前操作。

## 关于页

关于页顶部提供 EUI-Edits 项目仓库入口。文件展示区使用与标签栏、文档库共用的六类文件图标，并以文件关联页面的胶囊样式展示代表格式。版本卡片下方依次是开源许可和技术栈，EUI-NEO 入口位于技术栈卡片。

## 更新提示

设置 → 关于的「当前版本」卡片可开启或关闭更新提示。默认开启，启动约 5 秒后在后台查询 GitHub Releases，距上次自动尝试未满 24 小时时跳过。只比较正式稳定版本及其 Windows x64 资产；网络或读取失败时静默。新版浮窗可关闭或打开发布页，下载和更换由用户操作。`automatic_update_check` 和 `last_update_check` 保存在当前用户设置中。

## 编辑器设置与字体

设置的“外观”页按颜色与风格、界面大小、语言与动效分组；“编辑器”页按文字与排版、工作区、辅助信息分组。每行按自身标题和说明的实际换行计算高度，窄窗口中控件移到说明下方，滚动范围包含所有分组、预览及底部恢复入口。

界面字体入口位于“外观 → 界面大小”；正文、代码字体入口位于“编辑器 → 文字与排版”。三个入口共用字体选择页，进入时选中对应类别，仍可在页内切换类别。字体未自选时显示“系统默认”；正文和界面当前默认使用微软雅黑，代码使用系统等宽字体。“恢复系统默认”只恢复当前选中的字体类别，保留其他字体及文稿内容。

字体选择页顶部提供名称/文件名搜索、结果数量和“清空”。英文名称忽略 ASCII 大小写，中文按原文匹配；空格分隔的多个词须全部匹配。代码类别继续使用等宽筛选，当前已选代码字体保留原有可见规则，搜索本身不会选中或应用字体。切换类别保留搜索词并回到结果列表顶部，从设置主页面重新进入时清空搜索并聚焦搜索框。无匹配时提示修改或清空搜索；窗口较矮时可滚动整页到列表及底部操作。

界面字号旁展示按当前界面字体和字号绘制的菜单、文档库文字样张；正文字号旁展示标题、中英正文及代码样张，使用当前正文、代码字体和生产 Markdown 排版参数。改变字号或字体后预览随之更新，样张不打开或改写文稿。预览单位为逻辑像素，最终显示同时受系统 DPI 与界面缩放影响。

“界面模式”和“自动收纳”位于“编辑器 → 工作区”，状态栏与行号位于“辅助信息”。

外观页底部的“恢复外观默认值”恢复语言、主题、界面风格、界面字体和字号、缩放及动画；保留正文字号、正文和代码字体及其他编辑器偏好。编辑器页的“恢复编辑器默认值”恢复正文与代码字体、正文字号、限制行宽、界面模式、自动收纳、状态栏与行号；保留外观偏好和侧栏宽度。两者都须确认，取消或关闭确认框不改变设置；确认始终对应点击时的分类。文件与系统、关于页不提供分类恢复。文稿、最近文件、更新提示偏好和 Windows 文件关联不在恢复范围。若设置写入失败，提示默认值仅在本次运行生效。
