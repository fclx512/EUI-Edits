## 当前验收重点

| 工作 | 完成条件 |
| --- | --- |
| 日常编辑体验 | 在当前候选上检查中英/emoji、软换行、反向和跨视口选区、撤销、切页与外部回写，记录保存读回结果 |
| 窗口与输入 | 覆盖真实中文 IME、持续拖选、窗口缩放、菜单、设置往返和正常退出 |
| 菜单风格与 CPU | 外观已由用户确认无异常；用户报告另一台物理 Windows 10 电脑实测通过；同轨迹 CPU 归因与连续相同裁剪复用已完成，本地报告保留测量范围 |
| 渲染与设备专项 | 后续涉及硬件路径、DPI 适配或设备恢复的改动，按对应专项范围验证 |
| 导图 | 验证正文映射、焦点、滚动、缓存失效与超限回退，分别测冷启动、大图和缩放 |
| 可用版本 | 冻结当前范围，执行完整检查、独立包与最终资产 GUI；流程见[发版说明](发版流程.md) |

本菜单任务的物理 Windows 10 通过来自用户异机实测报告，未绑定本仓库候选 EXE 的哈希。按用户确定的范围，低配和多屏 DPI 已移出本菜单任务的活动验收项，不作为本任务收尾或发版阻塞；后续相关专项另定范围。

专项 IME、持续拖选与设备场景的完整矩阵由对应任务维护。间歇窗口图标缺失和历史 OPT-001/OPT-002 保留待复现；Win11 最大化按钮的 Snap 悬停布局尚未实现。

性能优化继续以具体体验问题和当前基线为起点，复跑方法见[性能测试方法](性能测试方法.md)。渲染默认策略变更前，同一 EXE、同配置比较软件 DC、软件 Hwnd 和硬件优先 Hwnd，记录 CPU、帧阶段与各项内存。
