## 当前实现

窗口最小宽度配置由608缩为420逻辑像素，最小高度保持384。标签操作区按“新建 / 列表 / 置顶”排列；图钉使用自绘线条，当前窗口置顶时高亮，再点取消，状态不落长期设置。按钮命中区从标题拖拽中排除，右侧仍保留拖动空隙。3项定向回归与最小尺寸、真实置顶层级、新建/列表及正常退出记录见本地[更窄窗口与置顶](../local-docs/repo-docs/更窄窗口与置顶-20261021.md)。

窄窗口自动精简：设置→编辑器提供默认开启的“自动收纳”，视图菜单提供同一偏好的勾选开关。设置说明简化为“窄窗收起辅助界面，拉宽后恢复。”置顶悬停提示按文字加20逻辑像素留白测量宽度，与现有按钮提示一致。名称、菜单和提示本轮核对见本地[自动精简文案与提示](../local-docs/repo-docs/自动精简文案与提示-20261021.md)。逻辑宽度低于800进入精简、达到880恢复，临界区间保持当前布局以避免反复折叠。精简时隐藏文档库、大纲、格式工具栏、TXT写作胶囊、状态栏及行号，菜单收为单一入口，保留文档切换和窗口控制。自动状态不写入设置，手动布局/行号/状态栏/大纲偏好原值保留；手动沉浸时保留退出按钮。正文、字体、保存和关闭规则沿用原逻辑。7项定向检查与小窗操作见本地[自适应窗口精简验收](../local-docs/repo-docs/自适应窗口精简-20261021.md)。
