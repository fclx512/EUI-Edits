# 渲染后端与 CPU 处理契约

本文记录 EUI-NEO 在 Win32 上的 Direct2D 渲染边界、资源生命周期和验收要求。它描述架构契约，不构成默认启用硬件加速的批准，也不替代绑定具体构建的测试报告。

## CPU 与 GPU 的职责

CPU 负责编辑模型、Markdown 解析、排版测量、字体回退、FreeType 字形栅格化、字形顶点装配、图片解码，以及部分阴影和颜色预处理。硬件优先路径由 Direct2D/GPU 绘制客户区图元、采样字形图集和图片位图；系统 DWM 负责桌面窗口合成。

文本与 UI 数据量小、分支多，并依赖撤销、IME、字体变化和布局状态。当前策略是由 CPU 生成可复用资源，再由 Direct2D 反复采样和合成。不能据此推断所有 CPU 工作都比 GPU 快；改变计算归属时，应把上传、同步、缓存和生命周期成本纳入同配置测量。

“GPU 渲染”在本项目中指客户区共享 Direct2D 路径。系统窗口框、原生文件对话框、IME 候选窗及 CPU 排版不属于 GPU 客户区绘制的替代范围。

## Win32 后端选择与回退

Win32 默认采用软件栅格化，并优先使用软件 DC/GDI 兼容目标。`NEO_D2D_SOFTWARE=0` 才请求硬件优先；软件模式下 `NEO_WIN32_DC=0` 可禁用 DC/GDI。准确策略以 `core/render/d2d/render_policy.h` 为准。

`core/render/d2d/d2d_backend.cpp` 创建 DC 或 Hwnd render target，并在目标创建失败时尝试软件路径。硬件优先是候选路径，不是设备可用性保证；保留并验证软件回退。进程启动选项、目标类型与失败回退要分别记录，不能把请求硬件等同于已确认的实际适配器。

切换全局后端会影响输入框、选区、Markdown、菜单、侧栏、状态栏和图片等共享绘制。应评估整体编辑器的真实行为，而非以单一组件或思维导图子集代表全应用。

## 字形图集与设备恢复

CPU 图集页是字形像素和索引的权威来源。D2D 可按实际已用高度创建较短位图，以减少上传与 GPU 资源；裁高上传必须继续使用源页尺寸计算 UV，不能因目标位图较短改变 UV 归一化。

上传高度向上按64行对齐并受源高度限制；未知占用高度回退为整页。同一活跃源页扩展时，现有 D2D 位图高度不缩小，避免丢失仍有效内容。设备丢失后清空 D2D 资源状态，再从 CPU 源页重建。`NEO_D2D_COMPACT_ATLAS=0` 可关闭裁高，作为同 EXE 对照；OpenGL/Vulkan 继续完整页上传。

CPU 页不能因 D2D 位图裁高而释放。图片 CPU 像素副本也承担设备恢复来源；删除它会要求重新解码并处理无路径资源。渲染目标及图像、字形资源的释放与重建须覆盖设备丢失和窗口尺寸变化。

## 缓存和资源预算

缓存键须覆盖文档身份、文本、装饰、字体、宽度及影响布局的版本。换页、外部回写、撤销、IME 和设备恢复不能因不完整 revision 键跳过更新。

缓存预算是该缓存的估算边界，不是进程内存上限，也不等于分配器实占。CPU 工作集、私有工作集、私有提交、GPU shared usage 和 GPU 引擎使用率是不同指标，不得相加或互相替代。进程测量要写明采样时点、峰值/场景结束口径及场景条件。

字形推进量随固定字号的字体 holder 复用，以完整 face 索引和 glyph 索引为键；后备 face 只追加，表随 holder 释放。每张表为 4096 槽、8 路集合，所有仍存活的表共享 2 MiB 显式对象预算；外部 TextPrimitive 持有的表也计入。该预算不包含 holder 指针、共享控制块和分配器开销。预算不足或分配失败时继续正常度量，释放旧表后可以重试。制表符、组合标记及加载失败的推进量不入表，`NEO_TEXT_CACHE_OFF=1` 禁用此层读写。位图绘制仍独立加载并栅格化字形，推进量命中不依赖上次 FreeType glyph slot 的内容。

避免为追求较小数字破坏恢复能力或稳定性。缩小固定图集可能使大字形无法放入并触发清页重栅格化；压缩渲染缓存可能增加重建与重绘；保留的源像素可能是设备恢复必需数据。每个优化要说明作用对象和未改变的资源。

## Markdown 宽度变化的可续跑排版

Markdown 编辑区启用自动换行时，可通过 `InputBuilder::widthReflowFrameToken(app::updateSerial())` 启用宽度变化的协作式排版。已有完整布局且正文、装饰、字体、DPI 和模式一致时，每次有效 UI update 最多推进一次草稿；同一 update 内的多次 compose 共用序号。推进使用 3 ms 软预算和 4096 次操作上限，后续片段由仅在任务存活时存在的 16 ms 计时器唤醒。计时从本片完成后计算，不保证固定完成时延，也不是整窗帧率限制。

草稿只对应最新宽度。期间显示并命中上一份完整布局；全部行、表格、几何和回调快照准备好后一起发布。新宽度替换旧草稿，回到已发布宽度则取消；正文、装饰、字体配置、像素比例、模式或合成状态不匹配时回到同步路径。首次加载、正文编辑、Markdown 解析和 IME 排版本身不因此变为可续跑。手动滚动按顶部实际行的源字节与行内偏移恢复；表格续段还保留活动列，跟随光标优先。

长普通段落、带样式段落及长表格单元格使用度量/换行游标。`TextPrimitive::MetricsCursor` 保留完整 UTF-8 输入和同步度量的物理推进量累加顺序，分片间释放字体锁；字体配置代次或 DPI 改变会取消结果。它在 UI 线程协作执行，没有引入后台线程或并发修改全局字体状态。操作系统直接替换字体文件而框架未收到配置失效，不属于该代次保证。

发布布局的回调持有独立快照；旧宽度回调只有在正文、预编辑字节、装饰和字体上下文仍一致时才可命中。已发布布局代次必须进入每个文字子元素的 dirty key；仅改变父元素的 key 不会使 Runtime 更新其保留的文字。快照的只读生命周期不意味着可在 `InputState` 析构后执行捕获其引用的修改型 UI 回调。额外的旧布局、草稿和回调快照会增加驻留内存，没有固定进程内存上限。

3 ms 是让出线程的目标，不能作为硬上限。首次字体加载、缓存复制/插入、几何构建、部分快照复制、发布与取消时释放容器等仍有原子成本。验证应覆盖持续换宽、停下等待完成、深度草稿取消及旧回调；同时报告单片成本、完成片数、总 CPU 工作量和最终布局一致性。CPU 调度探针不等于真实鼠标到屏幕延迟、FPS 或低配机器表现。

## 验收边界

### 编辑器纯色菜单与短动画

EUI-Edits 菜单和顶栏不再启用 FrozenBackdrop 或 cachedStrip。菜单使用主题底色 RGB 并强制 alpha=1；顶栏使用不透明 toolbar 色。菜单默认入场 120 ms、退场 70 ms、单块邻行高亮 75 ms；只对整体位置/透明度与高亮位置/颜色作有限过渡，不缩放文字。过渡期间整层透明度仍变化，不应将静止不透明等同于动画每一帧不透底。

菜单切换时旧层即时隐藏；回到正文时保留退出内容并立刻禁用输入。子级退场结束以一次有限计时回收隐藏树，动画结束后不保留额外唤醒。动画开关和 `NEO_FEEDBACK=0` 同时作用于全部菜单。既有装饰采样机制继续使用，输入/拖动/滚动不为此限频。

控件单行标签使用同一字体、字号、字重的 `Ag中文` 参考墨迹确定共享基线，涵盖菜单/下拉选项、checkbox/radio/switch、通用 tabs 和日期时间标题；不会随每个标签是否带降部字符而上下跳动。已按实际墨迹 Center 对齐的按钮、segmented、单行输入、侧栏及页签保持既有规则。

设置标题与说明作为完整墨迹块居中，说明采用真实换行宽度和显式行高。`TextPrimitive::measureTextInk` 与渲染共用布局；缓存覆盖解析后的字体持有者与代际、全文、物理字号、字重/斜体、wrap、物理宽度和行高，随字体或像素尺度变化重新计算。单行 API 保留兼容；不引入按字号或颜色凑偏移的缓存。

设置与编辑区各使用常驻轻量容器，仅构建当前页内容；进入设置和返回编辑区均使用200 ms / 4 DIP淡入，Opacity/Transform 同样遵守共享60 Hz。离开的页面即时卸下内容，初始编辑器直接显示，关闭动画时直接呈现终态。设置导航在事件阶段关闭瞬时菜单，返回请求正文焦点，不通过保留旧弹层实现页面退场。

### 显式冻结快照能力（当前编辑器不使用）

`FrozenBackdrop` 是显式启用的快照材质，不是通用实时 `blur()`。显式配置的弹层共享一个瞬时 session；调用方需保证唯一归属，打开后稳定取样一次，菜单期间复用，场景或设备变化时本次打开回退为主题底色。关闭重开创建新 session，不在同一次打开内循环捕获。

`cachedStrip` 使用另一份独立缓存，可由调用方显式配置内容窄条。Runtime 在首次稳定捕获时预绘制干净的源区域，排除光标、悬停提示及自绘光照，复制并过滤窄条后，再全量正常绘制最终帧。源区域验证先于裁剪，短窗口或非法区域直接回退。菜单与窄条同时需要首次捕获时可共用一次干净预绘制，资源和 session 仍分别管理。

调用方应只在标签、主题或窗口几何等离散切换创建窄条激活。完整来源签名覆盖正文、装饰、字体、布局、滚动和相关绘制状态；变化后本次激活保持纯色回退，不能按每次输入或滚动重新过滤。失效状态不再遍历完整来源签名，直到下一次激活；有效快照在已有绘制机会中仍有签名校验和位图绘制成本，不能称为零 CPU 开销。

窄条只保留过滤后的输出图。输入、输出与兼容目标的显式位图估算合计限制为 4 MiB，效果和驱动内部暂存不在该估算内，不能当作进程内存上限。`stripCaptures` / `stripFilters` 表示实际捕获与过滤次数，`stripReuses` 是命中缓存的绘制次数，也可包含首次捕获帧的正常绘制。稳定后不产生额外 deferred 绘制请求；没有常驻轮询或逐帧滤镜。

这两种能力保留在框架和专门探针内，当前产品没有启用入口。此前 `NEO_FROZEN_MENU` / `NEO_TOPBAR_MATERIAL` 应用试验开关已移除，设置环境变量也不会恢复菜单/顶栏快照。隐藏 Runtime/D2D 探针只覆盖其场景和后端，不能作为当前纯色菜单的实窗观感证据。

### 可选的局部 Reveal 光照

矩形可显式配置 `RevealEffect`；当前由 Direct2D 绘制径向边光、悬停底光与按压扩散，其余后端尚未实现该绘制效果。应用在 compose 末尾为有状态配色的可点击矩形及可用菜单项统一配置，直角风格且动画开启时使用主题强调色。禁用/不可命中子树、文字输入、拖动面板、点击拦截遮罩、窗口控制按钮和主题工作台配色样张不参与；正文及标签页的拖动表面保持原交互。`NEO_REVEAL=0` 可禁用，未设置时兼容旧 `NEO_SETTINGS_REVEAL=0`。

指针照明状态保存在运行时，所有 Reveal 控件共用最多 60 Hz 的提交节拍，并保留每个控件的最新位置与按压事件；不能只给各控件独立限频而让错相更新增加整窗重绘频率。直接标记按钮区域失效，不通过 `onMove` 或 `onFrame` 请求 compose。禁用/输入取消立即清除。普通装饰过渡共用以下60 Hz节拍，输入和几何交互不受节流。邻近边框可在指针位于按钮外时照亮；悬停与按压过渡有有限时长，静止收敛后不产生额外唤醒。配置与动画状态只为启用的控件分配。

### 装饰过渡的共享采样

Runtime 默认将 hover/press 平滑配色、颜色、tint、opacity、border/shadow，以及各类 UI 元素的 Frame、Transform、Radius、Blur 被动过渡，统一限制到共享的最多60 Hz，与 Reveal 使用同一相位。所有这些属性的插值计算与动画脏区提交都只在采样点推进，不能仅限制 opacity 而让几何动画继续驱动高刷新率循环。仅更新目标不标记动画脏区；采样时累积实际经过时间，批量输入仅最后一个事件推进装饰。首次启动或反向目标不消耗此前长暂停的时间，既有过渡可追赶经过时间。动画关闭及无动画即时状态仍及时应用。

只有装饰活跃时，Runtime通过 nextTimerWakeSeconds 调度下一采样，不以 isAnimating 请求显示器频率的连续帧；静止收敛后不保留装饰唤醒。缓存子树仍把装饰活跃视为需更新，避免省略收尾。未声明过渡的布局变化、滚动与拖动状态、输入/IME、计时器及媒体时钟保持原时序。被动几何过渡通过 nextTimerWakeSeconds 唤醒，不再以 isAnimating 请求显示器刷新率的连续帧。回调请求compose、内容变化、曝光等仍可额外绘制，不能把此策略说成整窗60 FPS上限。

Runtime::setDecorationFrameRateLimit(0) 用于全部被动过渡逐更新推进的诊断对照（Reveal仍60 Hz）；正数最多60。比较时保持同一输入采样频率、轨迹、控件数、主题和后端，分别记录update、paint、compose、full paint及终态唤醒。隐藏D2D表面可测量真实渲染调用成本，但不是原生输入或屏幕显示延迟证据。

D2D 径向画刷按渲染目标及主题 RGB 缓存，容量固定为 4；移动只更新中心、半径与透明度，目标更换、缓存释放及设备资源释放时清理。此路径不使用背景模糊。局部脏区减少界面组装与重绘范围，但当前 D2D 缓存仍整幅复制到窗口，不能将按钮面积直接换算为呈现代价。微基准、真实窗口和低配机器必须分别验证。

性能比较使用相同源码基线、配置、窗口尺寸、DPI、文档与输入轨迹，交错运行独立进程，保留预热、原始轮次、中位数、指标口径及源码/EXE SHA256。报告正负结果；嵌套阶段耗时不可直接相加。

像素合同、图集增长与溢出、UV 稳定、软件 DC/软件 Hwnd/硬件优先 Hwnd、曝光重绘和设备恢复应分别覆盖。正确性门禁通过不代表真实窗口验收通过；`EndDraw` 成功不代表帧已显示。

真实窗口验收应绑定候选 EXE 与独立配置，检查编辑、选区、Markdown 装饰、输入、IME、缩放、遮挡后重绘、正常退出及适用的设备恢复。注明 GPU/驱动、单屏或多屏 DPI、低配覆盖、持续拖选是否执行；未执行的轨迹标为 SKIP 或 NOT_RUN。

若把硬件路径设为默认候选，须同时验证软件回退及目标创建失败路径。组件微基准、静置窗口和单机帧时改善各自只支持其覆盖范围，不能推出低配性能、普遍时延改善或完整产品验收。
