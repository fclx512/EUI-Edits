# 如何运行 EUI-Edits

更新：2026-10-09。当前源码产品版本为0.1.2，Windows x64使用Win32/Direct2D。

## 正式包

从[仓库README](../README.md)的下载入口取得正式 `EUI-Edits-版本-windows-x64.exe`，双击运行；也可把一个文本/Markdown文件传给EXE打开。正式脚本生成的单EXE内嵌应用资源和许可，不要求旁置开发用assets目录。

开发EXE与正式包分别验收；不要把 `neo_editor.exe` 改名当发布包。本地开发候选的路径/哈希记录在维护者本地文档区（`local-docs/repo-docs/`），旧checkout绝对路径和 `out/latest` 不作为运行入口。

## 开发运行

按[README开发步骤](../README.md#开发)在本仓库新构建目录配置Win32/D2D、MSVC x64 Release；编译目标 `neo_editor`，运行该目录的 `Release/neo_editor.exe`。CMake不在PATH时见[构建指引](NeoEditor-发布构建说明-2026-10-02.md)。开发构建是否依赖外置资源由其配置决定，不套用旧GLFW/OpenGL规则。

## 基本操作

- `Ctrl+O` 打开、`Ctrl+N` 新建。
- `Ctrl+S` 保存、`Ctrl+Shift+S` 另存为。
- `Ctrl+,` 打开设置；字体、字号、主题、动画与显示选项在设置/菜单中调整。
- 文档库侧栏用于浏览当前库；顶部标签切换已开文档。未保存改动按当前确认/恢复流程处理。

不把“几MiB与小文档同样流畅”作为保证。性能条件、持续拖选及IME等未覆盖项记录在维护者本地文档区（`local-docs/repo-docs/`），本地旧版运行指南也保存在该区。
