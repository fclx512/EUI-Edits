# 如何运行 EUI-Edits

## 正式包

从[发布页](https://github.com/fclx512/EUI-Edits/releases)下载 `EUI-Edits-<版本>-windows-x64.exe`，双击运行，也可拖入文本、Markdown 或图片。资源和许可嵌入 EXE，无需旁置 assets。设置保存在当前用户的 `%APPDATA%/EUI-Edits/`。

常用操作、恢复与文件关联见[中文 README](../README.md#常用操作)。

## 开发预览

按[构建参数](NeoEditor-发布构建说明-2026-10-02.md)构建本仓库的 `neo_editor` 目标，运行该构建树中的 `Release/neo_editor.exe`。预览使用 `out/preview-1/` 至 `preview-3/`，交付前按[开发规范第 4 节](开发流程与交接规范.md#4-构建产物与-out-管理)检查版本与资源。

可用版本候选为 `out/stable-candidate/` 中的最终单 EXE，资产身份和验收状态见本轮本地交接。正式候选准备按[发版流程](发版流程.md)执行。
