# NeoEditor 主题导入

> **路径说明（2026-10-04）**：文中提到的 `参考/…` 本地采集目录（Obsidian 样式规格、测量 JSON、标本截图、probe-vault、验证脚本等）已随发版清理整体删除。这些引用仅说明当时的取证方法与数据出处，结论仍有效；如需复查请按文中流程重新采集。


## 入口与格式（2026-10-18 原生试装）

设置 → 外观 → 主题库，可打开主题工作台，也可导入 Obsidian 的 `theme.css` 或同目录带 `theme.css` 的 `manifest.json`。文件选择后先展示明暗两侧的导入报告；确认后创建独立草稿，当前应用配色保持原样，直到“保存并应用”。取消或读取失败不会替换已有草稿。保存到 `%APPDATA%/EUI-Edits/themes/` 的新 JSON 文件，不改导入源文件。

## 界面风格（圆角/直角）

设置 → 外观 → 界面风格 提供“win11”（圆角）与“win10”（直角）两种控件几何；说明为“调整ui界面的风格”，与“动画效果”相邻。它是独立于配色的一条轴：切换明暗或主题文件不会改变界面风格，切换风格也不会改变颜色。设置落盘 key 为 `ui_style`（0 = 圆角，1 = 直角）。

主题 JSON 的 `typography.radius` 只影响 Markdown 文档区（引用块、代码块、行内 chip 等），不改变菜单、标签栏、侧栏、按钮、对话框等界面控件；界面风格只改这些控件，不改编辑区正文。直角模式下滚动条、开关、单选框等胶囊/圆形控件保持原形。

直角风格的常规设置页使用连续纯色底面和细分隔线，桌面侧栏选中项带强调色竖条；控件位置、尺寸、文字及功能入口保持不变。字体选择、主题库及关于等独立页面沿用各自呈现。圆角风格保留原来的设置卡片。

菜单与顶栏使用主题纯色。文件/编辑/视图、窄窗合并菜单、正文和文档库右键、查找选项、标题和语法语言选择均取消背景快照、模糊和颗粒；菜单底色沿用主题 RGB，强制不透明，导入主题的半透明 surface 也不会在菜单静止时透出正文。顶栏沿用 toolbar 配色并强制不透明。此前的右侧接缝及滚动条留白修复保留。

菜单动画试用统一短过渡，位移、尺寸、圆角等被动过渡与颜色/透明度共同限制到60 Hz：默认 120 ms 淡入并移动 4 DIP，70 ms 退场，文字始终保持原字号与比例。过渡期间整层透明度会变化，静止后为纯色不透明。切换到另一个菜单时立即隐藏旧菜单，避免两组文字叠加；返回正文时才播放退场。每级只用一块高亮，邻行之间用 75 ms 跟随，首次进入或跨多行跳转直接定位。子级退场保留文字但立刻禁用输入，结束后回收隐藏行树。动画关闭或 `NEO_FEEDBACK=0` 时即时切换，不增加闲置轮询；已有直角局部亮边沿用原设置。

直角亮边使用独立的窗口视觉指针坐标。鼠标跨入顶栏拖窗区时，邻近控件的边光继续按距离衰减；点击、悬停、拖窗及缩放仍沿用原输入通道。离窗、失焦、禁用输入或取消输入时清除视觉状态，不把非客户区鼠标消息转成控件点击。

工作台以配色为主，提供 26 项可编辑颜色（每侧独立），不提供文件图标编辑。颜色可按样张位置选择、查看影响范围、修改 RGB 与不透明度、恢复单项、撤销/重做和对比修改前。`selectionBackground` 只控制正文文本选区；界面强调色、按钮和光标使用独立的 `accent`。排版面板提供按当前正文字号换算的像素值，并可复制到新主题。

EUI-Edits schema v1 保持兼容；schema v2 使用独立的 `light`、`dark` 对象。JSON 颜色格式仍兼容全部 32 个字段（包含 6 个历史图标字段及新的选区字段），缺字段回退本侧内置值。v2 的可选 `workbench` 对象持久化 `lightBaseline`、`darkBaseline`、来源和导入报告；保存或重新打开后，恢复目标仍是原始导入快照，不会变成上次保存的当前值。普通 JSON 的排版字段仍兼容。

## 本地自动配色与完整样张

主题工作台使用同一工作区：左侧保留完整样张，右侧按需显示配色、单色编辑或排版设置。配色面板选择起始颜色，比较“素净 / 柔和 / 鲜明”候选；试览不会写入草稿，明确采用后才改变草稿配色。也可直接点选样张，沿用已有配色进行微调。生成完全在本地运行；MCU C++ HCT 提供色调计算，EUI 的语义映射覆盖 26 个配色项。

点选样张位置后，右侧显示对应颜色设置，支持浅深切换、修改前对比、恢复和撤销。颜色列表按组展开，排版使用独立面板；保存时再打开命名与确认对话框。导入先审阅报告，确认后创建独立草稿。返回主题库保留本次会话的草稿，关闭应用前会检查所有未保存草稿。

手调 RGB 或不透明度会固定当前明暗侧的此项颜色。固定色在所有候选和采用结果中保留，另一侧独立；可主动解除固定。导入主题默认保留读取成功的颜色、仅补未导入色；关闭该选项后允许替换这些导入色，但仍保留手动固定色。混合保留色与生成色后、或手调后，仍应在样张中检查实际可读性。

采用一套候选、固定切换、单项恢复和全部恢复均可撤销/重做。单项恢复回到最初/导入时颜色并解除该项固定；全部恢复还原两侧颜色和排版、清除固定及当前配方，可一步撤销。保存主题会额外保存 `lightLocks` / `darkLocks` 及可选 `autoRecipe`（seed、variant、round）；旧主题没有这些字段也可读取。恢复基准不会随采用或保存前移。撤销历史属于本次编辑会话，关闭应用后不保留。

完整样张包含侧栏、工具栏、文稿、选区、光标、引用与代码，支持点选定位关联设置并高亮相关位置。文稿使用生产 Markdown 组件与自然换行，代码 token 和部分样张几何单独绘制，不承诺与编辑器逐像素一致；预览不打开或更改用户文档。窄窗口省略部分工具栏示例按钮，样张侧栏和正文各自滚动。排版面板显示像素值，默认只修改当前明暗侧；复制到新草稿时保留两侧各自参数。

保存仅创建新文件；内容未变且上次保存的磁盘文件也未变时，重复保存或应用复用该文件。文件被外部修改或移除后再保存，会另建文件。返回主题库保留会话草稿，关闭应用选择保存时会逐一处理所有未保存草稿，再进入正文文档的关闭确认流程。

## Obsidian CSS 子集

解析器读取 `:root` / `body` / `html` 和 `.theme-light`、`.theme-dark` 的变量声明。支持十六进制、逗号语法 `rgb(a)`、`hsl(a)` 与同侧 `var()` 链。只读取配色，不执行 CSS 排版、普通选择器、`calc()`、`color-mix()` 或插件样式；不再读取 CSS 字体、排版及图标变量。`--text-selection` 映射为独立选区色。

报告逐项区分读取成功、未映射、变量缺失、缺少该明暗模式、变量无法解析、不支持的表达式和非法颜色。未成功读取的颜色使用该侧内置默认值，不继承此前自定义主题。计数以每侧 26 个工作台颜色为分母，不代表整个 Obsidian 样式兼容比例。

读取失败（包括文件缺失、格式错误、没有可用颜色）保留当前主题。单个主题文件上限 8 MiB。社区主题依赖的 Obsidian 基础 CSS 不会自动补入，覆盖数较少时可在工作台继续调整。
