# 查找替换与选区范围

查找使用 UTF-8 字面匹配，提供区分大小写、全词匹配和回绕。单项替换依据当前正文实际选区识别命中；选区不对应命中时先定位下一项，再次操作才替换。无匹配查询不会破坏用户或撤销恢复的无关选区。

## 使用范围

1. 在正文中选中需要查找的范围，正向、反向及跨行选区均可。
2. 打开查找或替换，在查找选项中选择“选区内查找”。打开查找时可能自动预填查询并高亮命中；范围仍取原来的正文选区。
3. 此后导航、回绕和替换均限制在该范围。重新手选正文范围后，再选择“选区内查找”可重设范围；选择“全文查找”明确恢复全文搜索。

宽度允许时，计数会标明“选区”或“选区失效”；选项菜单始终标明当前范围。查找面板保留紧凑布局。

## 文本和撤销契约

范围使用 UTF-8 源字节的左闭右开区间，不按屏幕视觉行或投影文本定位。匹配从范围起点开始，接受的命中不重叠且必须完整位于范围内；全词判断仍读取原文相邻字符，选区边界不人为制造词边界。

范围内的单项/全部替换沿用正文编辑和撤销漏斗。替换长度变化只调整范围末尾，范围外正文不变。全部替换可以一步撤销；删除整个范围后保留有效空范围，不自动扩大到全文。

其他正文编辑、撤销/重做或外部重载导致文稿或输入模型代次变化时，已启用范围失效。此时清空命中、暂停导航和替换并提示重新选择范围或切回全文；查询或选项变化不会自动解除保护。真实正文不一致时，替换不会用陈旧输入模型覆盖应用正文。预编辑期间的排队动作被丢弃，不在候选结束后补执行。

范围和候选选区属于各自 DocumentSession，切页不借用其他文稿的范围。关闭查找清除范围、候选与待展开请求；范围不写入设置或恢复格式。

## 缓存和开销边界

命中缓存包含正文代次、输入模型代次、查询/选项和范围代次。范围快照拥有所选文本及相邻码点，用于动作前核对实际字节与全词上下文；其附加存储随选区大小增长，不是零额外内存。自身替换后更新快照，其他编辑保持保守失效。

未变化的空闲帧不复制选区；单纯拖选时延后到消费范围的动作再捕获快照。范围导航复用匹配表，动作前的快照字节核对仍与范围长度有关。本文不承诺原生IME时延或整体性能收益。

实现入口为 `apps/neo_editor/ui/find_bar.h`、`model/find_search.h` 与 `state/app_state.h`。关键回归位于现有 `find_actions`、`find_search` 目标，两者已纳入正式门禁。无头测试不代替真实鼠标选区、焦点、输入法或统一候选验收。
