# EUI-Edits

简体中文 · [English](README_EN.md)

EUI-Edits 是面向 Windows 的轻量原生文本与 Markdown 编辑器，适合随手记事、文档写作，以及源码和配置文件的简单编辑。Markdown 在同一视图中即时渲染与原位编辑，格式随输入更新，不必在源码与预览之间切换。

程序采用 C++、Win32 与 Direct2D 构建，按需刷新界面，不嵌入 WebView。发行包为免安装的单个 EXE，支持多标签页、本地文档库和未保存内容恢复。

## 编辑体验

- **边写边看 Markdown。** 标题、列表、引用、代码块和表格直接呈现在文稿中，当前编辑区域显示源文。链接可以点击跳转，任务项可以勾选；本地图片点击后可预览、缩放与平移。
- **多标签页。** 每页独立保留光标、选区、撤销历史、折叠和文档库视图。重复打开同一文件会定位到已有标签；再次启动程序打开文件时，请求会转交给已有窗口。
- **本地文档库。** 侧栏浏览所选目录，包含隐藏文件与无扩展名文件，已打开的文件会标记圆点。支持 `F2` 重命名；目录在后台扫描并随变化刷新，打开文件时才读取正文。
- **各类文本编辑。** Markdown、纯文本、源码和数据文件均可打开。已识别格式提供基础语法着色，也可通过「文件语言…」手动切换；查找替换、自动换行和行号适用于日常编辑。
- **保存与恢复。** 保存时保留原文件的编码、BOM 和换行类型，并检查外部修改冲突。未保存内容定期写入恢复副本，异常退出后可恢复为独立草稿，确认后再保存到文件。

## Markdown 支持

| 语法 | 当前表现 |
| --- | --- |
| 标题（`#` 与下划线式）、段落 | ✅ 即时渲染，原位编辑 |
| 粗体、斜体、行内代码、删除线、下划线（`_.._`） | ✅ 支持 |
| 链接、Wiki 链接（`[[...]]`） | ✅ 可点击跳转 |
| 有序 / 无序列表、任务列表、引用 | ✅ 支持；任务项可勾选，引用最多四层 |
| 围栏代码块、表格、分隔线、frontmatter | ✅ 支持 |
| 本地图片（独占一行） | ✅ 显示图片，点击进入预览 |
| 行内数学 `$...$`、HTML | ⚠️ 数学按代码样式呈现；HTML 保留源码，不执行 |
| 公式排版、远程图片、高亮、注释、脚注、callout、标签 | ❌ 暂不支持，源码保持可编辑 |

Markdown 覆盖常见写作语法与部分扩展，不保证完整 Obsidian 兼容。

## 开始使用

从 [0.1.2 发布页](https://github.com/fclx512/EUI-Edits/releases/tag/v0.1.2)下载 `EUI-Edits-0.1.2-windows-x64.exe`，放在准备长期使用的位置直接运行，无需解压资源目录。旁置 `.exe.sha256` 文件可用于校验。程序面向 Windows 10/11 x64，目前未签名；Windows 11 已进行实机验证，Windows 10 尚未完成同等范围的测试。

**0.1.2 更新：** 修正表格中中文、emoji 和软换行文本的选择背景；减少输入组件中的正文副本、行号统计和目录过滤临时字符串；关闭动画时省去闭合菜单的隐藏内容构造。变化与测试边界见[发布说明](apps/neo_editor/RELEASE-NOTES.md)。

### 常用操作

| 操作 | 快捷键 / 方法 |
| --- | --- |
| 新建文本 / 打开文件 | `Ctrl+N` / `Ctrl+O`；也可拖入文件 |
| 新建 Markdown | 「文件 → 新建 → Markdown」 |
| 保存 / 另存为 | `Ctrl+S` / `Ctrl+Shift+S` |
| 关闭当前标签 | `Ctrl+W`；有改动时询问保存、放弃或取消 |
| 下一标签 / 上一标签 | `Ctrl+Tab` / `Ctrl+Shift+Tab` |
| 定位标签 | `Ctrl+1`–`Ctrl+8` 定位相应标签，`Ctrl+9` 定位最后一个 |
| 查找 / 替换 | `Ctrl+F` / `Ctrl+H` |
| 下一匹配 / 上一匹配 | 查找栏打开时按 `F3` / `Shift+F3`，或 `Ctrl+G` / `Ctrl+Shift+G` |
| 打开文档库 / 重命名 | 「文件 → 打开文档库…」；侧栏聚焦项目后按 `F2` |
| 打开设置 | 「视图 → 设置…」或 `Ctrl+,` |

新建文档第一次保存时选择文件名与位置。遇到乱码，可从「文件 → 以编码重新打开」选择编码；保存失败、编码无法表示新字符或取消保存时，正文会保留，原文件不会被静默替换。

图片预览中，滚轮缩放、中键拖动平移，左键点击或 `Esc` 关闭。

### 设置、恢复与文件关联

设置保存在当前 Windows 用户的配置目录，不随 EXE 移动：

| 位置 | 内容 |
| --- | --- |
| `%APPDATA%\EUI-Edits\settings.ini` | 外观、字体、布局、最近文件等偏好 |
| `%APPDATA%\EUI-Edits\session` | 标签会话及未保存内容的恢复副本 |
| `%APPDATA%\EUI-Edits\themes` | 主题库中的本地主题 |

异常退出后，恢复内容作为独立草稿打开，不自动覆盖原文件。正常退出完成保存或放弃确认后会清理恢复会话，下次不会自动重开全部标签。恢复副本定期写入，不是逐次输入的即时保存，重要内容仍应主动保存。

在「设置 → 文件与系统」中可登记当前用户的文件「打开方式」，首次预选 TXT 和 Markdown。默认应用需另在 Windows 中选择；移动或重命名 EXE 后应重新登记关联。脚本文件按文本编辑，程序不会执行其中的代码。

## 外观与个性化

多数设置立即生效，并在下次启动时保留：

| 项目 | 可调整内容 |
| --- | --- |
| 语言与主题 | 简体中文 / English；明暗主题可跟随系统或固定选择 |
| 字体 | 正文、代码与界面分别设置；支持导入 `.ttf`、`.otf`、`.ttc`，代码字体检查是否等宽 |
| 字号与缩放 | 正文字号 12–32、界面字号 12–18；在系统 DPI 基础上额外缩放 80%–200% |
| 阅读布局 | 行号、状态栏、自动换行；限制行宽可收窄并居中正文 |
| 文档库与动画 | 简洁 / 文档库视图；悬停、按压等反馈动画可关闭 |

状态栏显示文件位置、文档语言、编码、换行类型、行数和字符数，可切换文档语言与自动换行；窄窗口中部分信息会收起。字体来自本机或自行导入，发行包不附带字体。

**本地主题导入为测试功能。** 从「外观 → 主题文件（测试）→ 主题库…」选择 JSON 或 CSS，也可将文件放入上述 `themes` 目录。Obsidian 主题可选择 `manifest.json`（同目录需有 `theme.css`）或直接选择 CSS；导入只映射可识别配色，不执行 CSS，不保证还原布局与插件样式，可随时返回内置配色。

## 资源占用

界面按需刷新；标签切换尽量复用排版与高亮缓存，超出缓存预算时释放较少使用的衍生数据；文档库只扫描元数据，不一次载入目录中的全部正文。关闭交互动画后，悬停和按压不再产生过渡帧。

以下为 **0.1.0 正式 EXE 在 2026-10-05 的闲置内存实测**，单位 MiB。环境为 Windows 11、默认 Win32 / Direct2D 软件渲染、浅色主题、125% 系统缩放，开启自动换行与限制行宽。每场景使用独立配置启动三次，加载后静置 10 秒，再各采样 20 次；表中为各轮中位数的中位数。

| 场景 | 整体工作集 | 专用工作集 | 专用提交量 |
| --- | ---: | ---: | ---: |
| 空白文档，1 个标签 | 48.6 | 16.8 | 22.0 |
| 3 个小 Markdown 标签，合计 2,580 字节，逐页访问后静置 | 57.8 | 23.4 | 32.2 |
| 9 MiB 纯文本，73,728 个文件行 | 184.5 | 152.6 | 194.4 |
| 9 MiB Markdown，同等行数，每行含列表、强调和行内代码 | 306.6 | 274.5 | 322.1 |

整体工作集是当前驻留 RAM 的进程页面，专用工作集是其中不可共享的部分；专用提交量不要求全部驻留 RAM。三列不能相加或互相替代，1 MiB = 1,048,576 字节。上述条件、EXE 校验值与原始数据保存在维护者本地记录中，不随仓库分发。

占用还受行数、Markdown 结构、撤销历史、标签缓存和图片解码影响。这些结果不含编辑与保存过程，不是交互峰值或固定上限；大文件不一定保持小文档的占用水平。

## 当前范围

EUI-Edits 聚焦本地文本编辑，不提供知识库管理、代码补全、编译调试、脚本执行或演示模式。

| 项目 | 支持与边界 |
| --- | --- |
| 文件 | 默认打开上限 **64 MiB**；拒绝超限、疑似二进制或无法可靠解码的文件 |
| 编码 | UTF-8、UTF-16 LE / BE、Windows ANSI 代码页；保存保留原有编码、BOM 和 LF / CRLF 特征 |
| 文档库 | 不递归进入符号链接目录或目录联接点的目标；部分显式文件操作同步刷新，大型目录可能需要等待 |
| 恢复 | 最多 **256 个标签项**，恢复正文读取限额为单份 **256 MiB**、合计 **1 GiB**；清单损坏或正文缺失时保留数据并提示，恢复可能不可用 |

## 开发

构建需要 Windows、Visual Studio 2022 / 2026 或 Build Tools（安装 C++ 桌面开发与 Windows SDK）、支持对应生成器的 CMake，以及 PowerShell 5.1+。运行检查另需 Python 3；打包使用 MSVC 自带的 `dumpbin.exe`。第三方依赖源码随仓库提供。

在仓库根目录的 PowerShell 中运行：

```powershell
# 翻译与选定的 Win32 / Direct2D 正确性检查
.\scripts\check-neoeditor.ps1

# 编译 Release x64，并生成单 EXE 与 SHA256 校验文件
.\scripts\package-neoeditor.ps1 -Version 0.1.2
```

产物位于 `out/euiedits-0.1.2-single-exe/`，文件名为 `EUI-Edits-0.1.2-windows-x64.exe`。打包采用 Win32 / Direct2D、静态框架与 MSVC 运行库，嵌入图标和许可证，并检查版本、DLL 依赖与许可证导出；真实窗口的交互验收需另行进行。

脚本自动寻找工具；查找失败可用 `-CMake`、`-Generator`，检查脚本另有 `-Python`，打包脚本另有 `-Dumpbin`。重新构建时可用 `-OutputDirectory` 指定新的打包输出目录，已有发行文件不会被覆盖。源码迁移后使用新构建目录，勿复用仍记录旧路径的 CMake 缓存。打包脚本含中文注释，请用 PowerShell 7（`pwsh`）运行；Windows PowerShell 5.1 会按 ANSI 代码页读取无 BOM 的脚本并报语法错误。

源码目录 `apps/neo_editor`、CMake 目标 `neo_editor` 及上述脚本名仍沿用内部标识，产品与发行文件名称为 **EUI-Edits**。更多打包参数与历史验收记录见[发布构建说明](docs/NeoEditor-发布构建说明-2026-10-02.md)，其中旧名称与绝对路径仅作历史参考，当前打包配置以脚本为准。

维护与后续开发见[文档导航](docs/目录说明.md)。
