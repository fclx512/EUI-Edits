本清单只评估编辑区的 `lp_plan → lp_decorations → components::input` 路径。只读预览使用另一套 `components/markdown.h`，不能以它的效果代替编辑区验收。

2026-10-01 产品范围调整：以记事本替代和常用 Markdown 编辑为目标；公式排版、远程图片加载及演示模式不再列为待办。复杂高级样式由外部文档软件查看使用。内存优化追求体验不退化和实际收益，不使用 100MiB 硬门槛。

## 固定探针与验收

人工逐项对照文档为 `tests/assets/markdown/manual_style_matrix.md`，覆盖常见 Markdown、GFM 和 Obsidian 扩展；其中的缺口用例用于核对现状，不表示已支持。固定截图样例为 `tests/assets/markdown/divider_visual.md`、`live_preview_coverage.md`、`frontmatter_coverage.md` 与本地 `sample.png`。运行 `python -B tests/probes/verify_markdown_visual.py`：脚本使用隔离的 APPDATA 和独立进程，不改用户当前文件或设置；保存深浅两套 `divider-*.png`（含活动行）、`coverage-*-p1..p6.png`、`frontmatter-*.png` 到 `tests/assets/markdown/screenshots/`。若本机保留参考资料 `参考/obsidian-style/app.css`，还会生成 `obsidian-default-*.png`。断言分隔线恰好为连续 2px，活动行隐藏、frontmatter 顶部不误画，滚动后的六张页面互不相同。截图展示标题、引用、列表、任务框、代码块、表格、四种分隔线和本地图片。

尚需人工扩验：限制行宽开关、125% 系统缩放、窄窗口换行、错误图片、选区及各语法片段的活动行源码。截图是固定回归基线，不能代替这些交互检查。

自动检查分三层：`lp_decorations` 验证语义与装饰；`neo_editor` Release 构建验证绘制接线；实机截图验证色、宽、高和裁剪。后续每修一项都更新本表及探针，再对照 `参考/obsidian-style/probe.md` 的 Obsidian Live Preview 标本。性能回归沿用 `tests/unit/perf_benchmark.cpp`，大文档和工作集数据单独记录。

2026-10-01 的 Win32 UI/样式改进与实机证据见 `docs/NeoEditor-UI与MD改进验收-2026-10-01.md`。旧 screenshots 目录中的历史截图不能替代当前构建。剩余重点是超宽表格的访问方式及扩展语法；Obsidian 主题导入的现状见 `docs/NeoEditor主题导入.md`。

后续的文字垂直居中、引用层级、任务交互、动态鼠标光标与125%坐标修正，见 `docs/NeoEditor-MD样式与交互验收-2026-10-01.md`。固定对照样本为 `obsidian_interaction_review.md`，实机输入探针为 `tests/probes/markdown_interaction.py`。

同日补充的空代码背景、原生列表圆点、菜单/文档库/链接反馈、字体页及异常字体启动恢复，见 `docs/NeoEditor-MD交互与字体安全验收-2026-10-01.md`。探针为 `md_followup.py`、`font_picker.py`、`font_startup.py`；浅色100%和深色150%使用系统125%缩放，最终构建hash与恢复范围在验收文档中记录。自选字体异常退出后会保守回退；预检不保证任意罕见字形或验证后被替换的文件安全。

## 2026-09-27 首批验证记录

- `lp_decorations`：通过；覆盖 `---`、`***`、`___`、`- - -`，活动行源码，以及 setext/frontmatter 不误画。
- `neo_editor` Release：编译通过；`git diff --check` 无空白错误。
- 实机画面：改用隔离进程截图探针后，固定深浅色画面已保存；分隔线像素、活动行、frontmatter 断言通过。`Paragraph` 后有空行再接 `---` 原被误判成 setext，现已要求两行相邻，加入回归断言。
- `perf_benchmark`：两轮九项护栏分别有 1 项和 4 项超标。两轮 `decor/20000` 为 8.35ms / 6.79ms，旧基线 4.33ms（护栏 6.50ms）；其它场景也明显波动。本轮不能据此宣称性能护栏通过；需要在稳定负载下与改动前同机对照。分隔线的附加状态采用复用颜色字段 + 单字节宽度，避免为所有行增设一份颜色。
