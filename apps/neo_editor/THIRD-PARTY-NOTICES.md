The application icon (`assets/icon.ico`, `assets/icon.png`, `assets/icon.svg`) is a EUI-Edits project asset. `assets/icon.ico` is compiled into the executable's Windows icon resource with common DPI sizes. The About page extracts the selected size-specific PNG generated from the same SVG master into the app's private cache; the executable contains the source bytes and needs no packaged asset directory. `assets/icon.png` remains an accompanying source asset. The document-group icon resources are generated by EUI-Edits's in-repository vector geometry generator and embedded in the executable.

No font files are bundled: interface and editor text render with Windows system fonts (Microsoft YaHei by default, selectable in settings), and every icon is drawn from the project's own vector geometry. Example artwork, music, shaders, the JingNanJunJunTi / YouSheBiaoTiHei / Font Awesome desktop fonts, test files, and user settings/recovery data are excluded from the package. Windows system fonts and operating system DLLs are used from the installed OS and are not redistributed. GLFW, glad, SDL2, Vulkan, and optional modules are not dependencies of this package configuration.
