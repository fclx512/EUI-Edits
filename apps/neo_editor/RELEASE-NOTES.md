# EUI-Edits @NEO_EDITOR_VERSION@ — 发布说明

**EUI-Edits 0.2.0 版本说明。**

## 本次更新

- **主题工作台：** 左侧样张、右侧设置，在同一工作区调整浅色和深色主题。支持本地自动配色、26 项颜色编辑、单项固定、排版设置、修改前对比及撤销/重做。Obsidian CSS 导入先显示读取报告，确认后创建草稿；保存为新的本地主题文件，不改导入源文件。未保存主题草稿在关闭应用前会提示处理。
- **写作与导航：** 增加 Markdown 写作工具栏与沉浸写作入口，调整标签栏和窗口顶栏；纯文本写作按钮浮动显示。Markdown 与 Wiki 本地链接支持同页和跨页标题跳转，编辑链接时自动聚焦并全选目标。行内代码间距同步参与换行与光标几何。
- **查找替换：** 支持在选区快照内查找和替换，范围失效时停止使用旧范围；批量替换可一步撤销。单项替换根据当前实际选区识别命中，未选中命中时先定位下一项，并遵循回绕设置。
- **文件与恢复：** 提供“转换为 UTF-8”，保留正文、撤销历史及换行类型。新建文件使用禁止覆盖的原子发布，已有文件保存后回读核对；无法确认保存成功时保留修改状态和恢复稿。恢复会话核对正文标识，避免使用已被外部改写的恢复内容。
- **文档库与编辑基础：** 文档库按层、分批后台加载，展开目录后再读取子项；筛选明确限于已加载内容。改进输入预编辑、选区显示、文本图集和布局回调，并扩展对应回归检查。
- **构建与发布：** 统一版本预检、完整正确性门禁与独立单 EXE 打包，保留源码身份和失败诊断；新加入的自动配色依赖与许可证随源码和发行包提供。

## 验收边界

主题导入只读取支持的配色，不执行 CSS，也不保证还原 Obsidian 布局或插件样式。自动配色在本地运行，混合固定色或手调后仍需检查实际可读性。主题草稿及其撤销历史仅在本次应用会话内保留，长期使用请保存为主题文件。

本版本面向 Windows 10/11 x64，未签名；Windows 10、低配设备、多屏混合 DPI、持续拖选、完整原生 IME 矩阵及 GPU 设备丢失恢复的覆盖需分别记录，不作普遍性能保证。README 中 2026-10-15 的内存样本属于历史 0.1.4 开发构建，不代表 0.2.0 的实测结果。

更新方法：直接删除旧版本，然后在新版本中的文件关联点击应用并修复即可（如果此前已注册打开方式）。发布前的候选冻结、门禁、打包和验收顺序见[发版流程](../../docs/发版流程.md)。发布说明不附哈希文件表；最终资产哈希由维护者单独核验。
