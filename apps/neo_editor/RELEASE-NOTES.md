# EUI-Edits @NEO_EDITOR_VERSION@ — 发布说明

## 相比 0.2.0 的主要更新

0.2.1 主要修正无边框窗口的操作体验，并让正常编辑窗口在较小尺寸下更方便使用。

### 窗口与界面

- **设置页可以拖动：** 修正无边框下设置、字体选择和主题页面的拖拽判定，页眉空白区域可以移动窗口；返回按钮与窗口控制仍可正常点击。
- **窄窗菜单：** 空间不足时将顶栏菜单折叠为“菜单”入口，减少与标签页、窗口控制的重叠；兼顾中英文及较大界面字号。
- **自动收纳：** 在编辑器设置或“视图”菜单中开启。窗口变窄时收起文档库、大纲、格式工具栏、状态栏和行号，拉宽后按原有手动偏好恢复，沿用现有编辑、保存与关闭规则。
- **更小的正常窗口：** 缩小最小窗口宽度，保留菜单、标签页和窗口控制，便于临时记事与并排查看。
- **窗口置顶：** 新建与文档列表按钮右侧增加图钉按钮，点击切换当前窗口置顶；悬停提示采用与其他按钮一致的紧凑尺寸。

### 操作细节

- **滚动与缩放边缘：** 正文滚动条与窗口缩放区域分开，减少拖动滚动条时误触窗口缩放；沉浸模式按钮旁的空白区域支持拖动窗口。
- **浮层交互：** 修正图片、全屏导图预览及确认遮罩覆盖顶栏时的点击判定，预览显示在菜单与标签浮层上方。
- **无边框绘制：** 调整原生边框绘制和 DWM 边缘请求，减少系统标题绘制覆盖自绘顶栏的机会；Windows 10 阴影效果仍待实机确认。

### 下载与更新

用新 EXE 替换旧版本；如果此前已注册打开方式，在新版本的文件关联设置中点击“应用并修复”。设置和本地主题保存在用户配置目录，替换 EXE 不会清除它们。

### 使用说明

目标平台为 Windows 10/11 x64，程序未签名。本轮实窗验收在 Windows 11 完成；Windows 10、跨屏 DPI 和不同硬件下的表现仍需进一步验证。自绘最大化按钮暂不提供 Windows 11 Snap 悬停布局，早期偶发图标缺失尚未确认根治。

主题工作台仍为测试功能。主题草稿及其撤销历史仅在本次应用会话内保留，长期使用请保存为主题文件。CSS 导入只映射支持的配色，不执行样式，也不保证还原 Obsidian 布局或插件效果。
