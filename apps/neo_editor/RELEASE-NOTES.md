# EUI-Edits @NEO_EDITOR_VERSION@ — 发布说明

**EUI-Edits 0.2.0 版本说明。**

## 本次更新

- **主题工作台：** 左侧样张、右侧设置，在同一工作区调整浅色和深色主题。支持本地自动配色、26 项颜色编辑、单项固定、排版设置、修改前对比及撤销/重做。Obsidian CSS 导入先显示读取报告，确认后创建草稿；保存为新的本地主题文件，不改导入源文件。未保存主题草稿在关闭应用前会提示处理。
- **写作与导航：** 无边框窗口整合菜单、标签与窗口控制，标签可拖动排序。增加 Markdown 写作工具栏、打字机与专注模式，右侧大纲支持标题导航；纯文本写作按钮浮动显示。Markdown 与 Wiki 本地链接支持同页和跨页标题跳转，编辑链接时自动聚焦并全选目标。行内代码间距同步参与换行与光标几何。
- **查找替换：** 支持在选区快照内查找和替换，范围失效时停止使用旧范围；批量替换可一步撤销。单项替换根据当前实际选区识别命中，未选中命中时先定位下一项，并遵循回绕设置。修正英文界面大字号下窄查找栏的按钮溢出。
- **文件与恢复：** 提供“转换为 UTF-8”，保留正文、撤销历史及换行类型。从文档库新建文件时避免覆盖已有文件，保存后核对写入内容；无法确认保存成功时保留修改状态和恢复稿。恢复会话核对正文标识，避免使用已被外部改写的恢复内容。
- **文档库与编辑基础：** 文档库按层、分批后台加载，展开目录后再读取子项；筛选明确限于已加载内容。改进输入预编辑、选区显示、文本图集和布局回调，并扩展对应回归检查。
- **离线配色：** 自动配色依赖随程序提供，无需联网；相关开源许可与署名可在应用内查看。

## 使用说明

主题导入只读取支持的配色，不执行 CSS，也不保证还原 Obsidian 布局或插件样式。自动配色在本地运行，混合固定色或手调后仍需检查实际可读性。主题草稿及其撤销历史仅在本次应用会话内保留，长期使用请保存为主题文件。

本版本支持 Windows 10/11 x64，两个系统均已通过实机测试，目前未签名。不同硬件、系统、字体与显示设置下的界面和性能可能有所差异，不保证与截图或参考数据完全一致。README 中的内存数据来自历史 0.1.4，不代表 0.2.0 的实测结果。

更新方法：用新 EXE 替换旧版本；如果此前已注册打开方式，在新版本的文件关联设置中点击“应用并修复”。设置和本地主题保存在用户配置目录，替换 EXE 不会清除它们。
