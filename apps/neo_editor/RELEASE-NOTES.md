# EUI-Edits @NEO_EDITOR_VERSION@ — 发布说明

**EUI-Edits 0.1.3 版本说明。**

## 本次更新

- **表格与选区：** 修正表格单元格中中文、emoji 和折行文本的选择背景（此前单元格末尾的中文或 emoji 会漏画选区，表格折行后相邻行的背景高低不齐）。
- **输入与长行：** 编辑器构建时不再复制整份正文，行号槽复用已提交布局的源行数，减少长文档上的重复工作。
- **Markdown 重排：** 样式文本全量重排时复用字体文件解析；密集标记的长段落在一次排版内复用投影与源位置索引，减少自动换行重排中的重复工作。普通短行保留原计算路径。
- **思维导图：** 支持 Mermaid mindmap 子集的只读原位预览，可在代码块内切换源码与导图，缩放、平移并查看大图；不支持的语法或超过规模限制时保留可读源码。
- **输入法与视口：** 在渲染前同步光标和输入法位置；自定义视口先接收当前鼠标位置，再处理滚轮，修正快速移入后缩放使用旧锚点的问题。
- **文档库：** 过滤时按字节折叠匹配路径，不再为每个条目创建临时小写字符串。
- **标签与侧栏：** 在同一帧批量准备冲突标题和文档路径，减少多标签情况下的重复计算。
- **菜单：** 关闭动画且菜单收起时，跳过隐藏菜单内容的构造，顶栏与编辑器右键菜单都立即收起。
- **绘制资源：** 按实际使用区域上传字形图集，减少未使用区域的位图占用。默认保留兼容的软件绘制；硬件优先仍为可选测试配置。

验收边界：上述条目描述当前候选实现。组件 CPU 测量不代表整体响应或输入到屏幕时延；低配、多屏 DPI、持续拖选和设备丢失恢复仍需对应设备与真实轨迹验收。

更新方法：直接删除旧版本，然后在新版本中的文件关联点击应用并修复即可（如果此前已注册打开方式）。发布前的候选冻结、门禁、打包和验收顺序见[发版流程](../../docs/发版流程.md)。发布说明不附哈希文件表；最终资产哈希由维护者单独核验。
