# EUI-Edits 思维导图人工查看样例

这是一份可直接打开的测试文档，不是完整 Mermaid 兼容演示。

## 如何查看

1. 保持在 Markdown 实时预览模式，不要切到源码模式。
2. 点击下面某个 `mermaid` 代码块内的任意一行，把光标放在块内。
3. 从“视图”菜单选择“思维导图预览”。
4. 在预览中滚轮缩放、中键按住拖动平移；使用适应窗口按钮复位。
5. 按 Esc 或点击面板外空白关闭。文档不应变成未保存状态，正文也不应改变。

## 图二：宽树与长标签

将光标放到这个块内后再次打开预览，应看到“人工验收”而不是上一张图。

```mermaid
mindmap
  verify((人工验收))
    display[显示正确性]
      中文没有方框
      emoji 完整显示
      English letters remain readable
      这是一条较长的中文标签，用于观察节点尺寸是否完整包围文字而没有裁掉句子的末尾
    interaction[交互正确性]
      向鼠标位置缩放
      移动后可以找回根节点
      关闭后光标回到正文
    integrity[只读不变量]
      开关前后正文一致
      未保存星号状态一致
      撤销不应产生导图动作
    modes[外观与字体]
      浅色主题
      深色主题
      改字体或字号后重新预览
    limits[边界与回退]
      不支持完整 Mermaid
      不支持节点编辑
      不支持 XMind 文件
```

## 拒绝用例：不应伪造完整 Mermaid 语义

以下块使用本版不支持的样式指令。把光标放入后尝试预览，应提示无法预览并保留原始代码块，不应出现残缺的导图。

```mermaid
mindmap
  root((应当拒绝))
    child[原文保留]
  classDef warning fill:red
```

## 普通 Mermaid：不应被当成思维导图
