# Markdown 交互与样式对照

普通中文、English、数字 12345 与 emoji 🙂 混排；文字基线应垂直居中，行高稳定。
行内样式边界：**粗体文字**、`inline code`、_下划线_、~~删除文字~~，相邻内容保持普通样式。
链接 [Obsidian 帮助](https://help.obsidian.md/) 应有清晰的链接样式；悬停为可点击光标，正文为 I-beam。

## 任务与列表

- [ ] 未完成任务：复选框可见，点击一次只切换此项状态。
- [x] 已完成任务：勾选状态清晰，点击后只切换此项状态。
- [ ] 这是一个较长的未完成任务，用于检查文字软换行后与首行正文对齐。继续补充中文和 English words，观察第二行、第三行不会缩进到复选框下面。
  - 嵌套列表项：标记和正文之间留出舒服的间距。
    - 第三层列表项：缩进层级清楚，正文和标记对齐。

3. 有序列表从三开始，标记与内容之间保留间距。
1. 后续序号按列表顺序递增。

## 引用与任务组合

> 第一层引用：背景、左侧竖线和正文留白应协调。
> 引用第二行应与第一行正文对齐，竖线连续且不贴窗口边缘。
> - 引用中的列表项应保留合理缩进。
> - [ ] 引用中的任务项应可点击，悬停状态结束后恢复正确光标。
>   - 引用中的嵌套列表保持层级。
>   > 第二层引用：应显示独立且连续的竖线。
>   > - [x] 第二层引用中的已完成任务仍能单独切换。
>   >   > 第三层引用：层级和竖线间距清晰，不与文字重叠。

## 编辑与选择检查

拖选上面的任务说明和引用文字时，选区应覆盖实际文字；松开鼠标后选区结束，鼠标移出可点击区域再进入时光标样式应重新匹配目标。
点任务复选框不应移动文本插入点或启动正文拖选；按住复选框后拖出再松开不应误切换任务。
点击链接后按应用既有导航行为处理；链接编辑仍可通过现有右键操作完成。
