# Markdown 样式人工对照

在 EUI-Edits 的编辑区打开本文件，分别用浅色、深色主题检查。将光标移入、移出每个样例，核对源码标记的显隐、文字样式、行高、选区和点击位置；缩窄窗口再检查换行。`sample.png` 与本文件同目录，供本地图片测试使用。以下「扩展」段落是 Obsidian/GFM 对照用例，当前未支持的效果应记录为缺口，不应误认为文件损坏。

普通中文 English 123，标点、空格以及 emoji 🙂 混排。第二句足够长，用来观察窗口缩窄时是否在英文词间和中文字间自然换行，并检查续行是否贴近窗口右侧。

紧邻的第二段。上一段与本段之间应有段间距。

转义字符：\*不是斜体\*、\#不是标题、\[不是链接\]；实体：&amp;、&lt;、&gt;、&#169;。

## 03 · 行内样式

普通、**粗体**、*斜体*、***粗斜体***、~~删除线~~、`行内代码`、``含 ` 反引号的代码``。

下划线扩展：_单下划线_、__双下划线__。因当前解析器启用了 MD4C 的下划线扩展，这两例不按 CommonMark 的斜体/粗体解释；需核对源码隐藏后是否实际出现下划线。

嵌套强调：**粗体内有 *斜体* 与 `代码`**；*斜体内有 **粗体***；**跨行的
粗体片段**。将光标移到嵌套片段和两端标记处检查样式与源码。

HTML 下划线：<u>应带下划线的文字</u>。扩展高亮：==应有高亮底色的文字==；扩展注释：%%应隐藏的注释%%。

行内数学：$a^2+b^2=c^2$；货币边界：价格 $5 和 $10 不应误配成公式。

上标和下标扩展：x^2^、H~2~O；键盘标签 HTML：<kbd>Ctrl</kbd> + <kbd>S</kbd>。

## 13 · C1 列表呈现（语义冻结样本，与 Obsidian Live Preview 同条件对照）

呈现口径：有序组从组内第一项的字面数字起、按组内偏移 +1 递增，后续项的字面数字
不参与呈现；同层换标记（子弹字符 / 有序⇄无序 / `.` 与 `)`）开新组；空行不断组；
物理续行（缩进续段与 lazy 续段）与所属项共享正文起点；任务行只用复选框。

### 序号重启与组起点

3. 从三起
1. 字面 1 不参与呈现 → 应显示 4
2. 应显示 5

- 无序不计数
1. 换标记 → 新组应显示 1

5. 空行不断组：仍属上一组 → 应显示 2
6. 同组下一项 → 应显示 3

### 标题会打断列表

1. 标题后的新列表 → 应显示 1（不是接着上面数 4）

### 嵌套有序的各层计数

1. 外层一
   1. 内层一
   2. 内层二
2. 外层二（弹出内层后应继续计 2）
   - 内层无序（不计数）
3. 外层三

### 引用内列表与嵌套引用

> 1. 引用项一（应显示 1）
> 2. 引用项二（应显示 2）
> > 双层引用：左侧应画两条竖条

### 任务行与续行对齐

- [ ] 任务项：长任务文本用来观察软换行后续段与复选框后的正文左边界对齐。
  - 缩进续段：应与任务正文起点对齐（复选框 advance）。
- [x] 已完成任务
紧贴的 lazy 续段：源码顶格，但呈现时应对齐到所属项的正文起点。

- 普通项
  缩进续段：应与项目符号后的正文起点对齐。

[^note]: 脚注内容，包含一个 [链接](https://example.com) 和 `代码`。
